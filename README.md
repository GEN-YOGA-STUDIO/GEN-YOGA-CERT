# GEN-YOGA-CERT — entorno de certificación

Copia de la web GEN Yoga **solo con datos de prueba**. Se publica automáticamente con cada push a \main\ del repo GEN-YOGA (workflow \deploy-cert.yml\).

- URL de cert: https://gen-yoga-studio.github.io/GEN-YOGA-CERT/
- Producción (genyoga.studio) **no se toca desde aquí**: se sube con \
pm run publicar\ en GEN-YOGA.
- No editar a mano: este repo es un espejo publicado por CI.
